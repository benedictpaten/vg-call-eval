# Where the structural-variant gap against PanGenie actually is

Generated by `scripts/wgs/sv_delta.py`. Autosomes only, SVs >=50 bp, truth T2T-Q100.

## The gap as truvari scores it

| | TP | FP | FN | F1 |
|---|---|---|---|---|
| vg call | 13,526 | 12,163 | 10,095 | **0.5486** |
| PanGenie | 13,749 | 10,544 | 9,872 | **0.5739** |

Distinct truth variants behind those TP rows: 13,378 for vg and 13,600 for
PanGenie -- truvari emits a row per match, so a multi-matched variant repeats. The set
arithmetic below is over distinct variants; the totals above are rows, to stay comparable
with the published figures.

## 1. The recall gap, and the part of it that is actionable

- missed by **both**: 8,176 (69.7% of all missed)
- **vg only** (PanGenie found it, so the panel carried the allele): 1,891
- **PanGenie only**: 1,665

`vg only` is the population worth working on: the allele was demonstrably available and the
read model declined it. The same inference does not run the other way from these files.

## 2. Does the advantage survive requiring the right genotype?

truvari's default match is locus, size and sequence -- **not** genotype. It records the
genotype difference as `GTMatch`, so the same comparison can be rescored with a correct
genotype required. This matters here specifically: the read model's known SV defect was a
mis-genotyping one, invisible to a genotype-blind metric.

| | TP (locus match) | of those, GT correct | TP (GT required) | F1 (GT required) |
|---|---|---|---|---|
| vg call | 13,378 | 11,788 (88.1%) | 11,788 | **0.4810** |
| PanGenie | 13,600 | 12,410 (91.2%) | 12,410 | **0.5213** |

A locus-matched call with the wrong genotype is counted as both a false positive and a
false negative under the stricter rule, which is what a genotyper getting the copy number
wrong has actually done.

### Splitting the excess by type

| | same-length substitutions | genuine INS/DEL | total |
|---|---|---|---|
| vg call | 292 | 11,871 | 12,163 |
| PanGenie | 29 | 10,515 | 10,544 |
| difference | **+263** | **+1,356** | +1,619 |

Same-length substitutions -- REF and ALT of equal length -- are a representation artefact rather than an evidence one: truvari sizes such a record by its allele length and so scores it as structural. vg's output is multiallelic and carries them; PanGenie's biallelic-split output essentially does not.

**vg emits 1,356 more genuine insertion and deletion false positives than PanGenie**, so the substitutions account for only 263 of the 1,619 excess and the rest is real disagreement about what is there.

Rescoring with substitutions excluded from both sides:

| | TP | FP | FN | F1 |
|---|---|---|---|---|
| vg call | 13,526 | 11,871 | 10,095 | **0.5519** |
| PanGenie | 13,749 | 10,515 | 9,872 | **0.5743** |

The gap falls from 0.0253 to 0.0224, so **12% of the headline SV F1 gap is this one representation artefact** and the rest is recall.
